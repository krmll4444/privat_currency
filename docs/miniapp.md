# Проект 2: Mini App — дашборд з графіком

Статична сторінка з графіком історії курсів, що відкривається тапом на кнопку
всередині Telegram-бота (Telegram Web App).

## Мета
Дати змогу глянути графік USD/EUR за період і поточний спред, не виходячи з Telegram.

## Завдання
- [ ] Проста HTML-сторінка + Chart.js (без білд-системи, без залежностей)
- [ ] Дані бере з `history.jsonl` проекту 1 (через raw.githubusercontent.com або
      з тієї ж gh-pages гілки)
- [ ] Підключити Telegram Web App SDK (`telegram-web-app.js`) — щоб сторінка
      підхоплювала тему (світла/темна) і знала контекст користувача
- [ ] Захостити статику безкоштовно: GitHub Pages або Cloudflare Pages
- [ ] У `@BotFather`: `/setmenubutton` або inline-кнопка з `web_app` — вказати URL сторінки
- [ ] Перевірити відкриття зсередини бота на iOS і десктопі

## Стек
HTML/JS · Chart.js · Telegram Web App SDK · GitHub Pages / Cloudflare Pages

## Готовність (definition of done)
Тап на кнопку меню в боті відкриває сторінку з графіком історії курсів і поточним спредом.

## Залежності
Потребує `history.jsonl`, який генерує **Проект 1** — без нього графіку нема що показувати.
