# Проект 1: Rate Engine (ядро)

Бекенд без сервера — cron-скрипт, що опитує курси, рахує спред і шле сповіщення в Telegram.

## Мета
Періодично зчитувати курс USD/EUR з Приват24 і з Приват Бізнес, рахувати вигоду
конвертації USD → UAH → EUR, зберігати історію і сповіщати, коли вигідно.

## Відкрите питання (зроби першим)
Ендпоінт курсу "Приват для бізнесу" не задокументований публічно.
- Відкрити DevTools → Network на `otp24.privatbank.ua` (сторінка логіну, без входу),
  знайти XHR/fetch, що віддає курс.
- Або дістати вихідний код розширення "Курс валют ФОП (ПриватБанк)"
  (Chrome Web Store id: `giobplimenegjjbochlglapnpackpiop`) і подивитись, який URL
  воно смикає у `background.js`.

Без цього кроку проект не має сенсу починати — спочатку підтвердь джерело.
