# Проект 3: iOS Home Screen Widget (Scriptable)

Живий віджет на головному екрані iPhone, що без відкриття будь-чого показує
поточний курс і спред.

## Мета
Погляд на спред за одну секунду, без відкриття Telegram чи браузера.

## Завдання
- [ ] Встановити застосунок **Scriptable** (безкоштовний, App Store)
- [ ] Опублікувати з проекту 1 легкий публічний JSON-ендпоінт з останнім значенням
      (наприклад `latest.json` поруч з `history.jsonl`, віддавати через
      raw.githubusercontent.com або ту саму gh-pages)
- [ ] Написати JS-скрипт для Scriptable:
  - фетчить легкий `data/advice.json` (статус, дія, курси, доплата в грн на `TARGET_EUR`)
  - не тягне `history.jsonl` — файл росте ~96 рядків/день
  - колірний індикатор (зелений — вигідно, сірий — ні)
- [ ] Додати віджет на homescreen, обрати цей скрипт як джерело
- [ ] Врахувати обмеження iOS на частоту оновлення віджетів (система сама вирішує,
      орієнтовно раз на 15–30 хв — не контролюється скриптом напряму)

## Стек
Scriptable JS API (нативний, без збірки)

## Готовність (definition of done)
На головному екрані iPhone видно актуальний курс і спред без відкриття застосунків.

## Залежності
Потребує публічного `data/advice.json`, який пише **Проект 1** кожен cron.
